# 補記帳分類與項目格式調整

## 目標

讓補記帳沿用一般記帳的自動分類規則，並把使用者輸入的消費項目寫入 Item 欄位。

## 輸入與儲存格式

輸入 `補記帳 6/18 午餐 120` 時，系統應儲存：

- Date：當年度的 `06-18`
- Category：使用既有分類關鍵字判斷，`午餐` 對應 `Lunch`
- Item：`午餐`
- Price：`120`
- Raw：完整保留原始指令 `補記帳 6/18 午餐 120`

Item 不得再寫入 `補記帳` 或 `補記帳：午餐`。

## 處理方式

補記帳解析器把日期後、金額前的內容視為消費項目。收到有效指令後，沿用現有 `classify()` 函式，依 Google 試算表中的既有分類關鍵字決定 Category。一般記帳、查詢和刪除流程維持不變。

## 錯誤處理

日期或金額格式無效時，維持現有行為：不新增紀錄並顯示格式提示。

## 測試

先修改解析測試，確認 Item 是 `午餐`；再新增補記帳寫入流程測試，模擬既有分類規則回傳 `Lunch`，確認寫入資料為日期、`Lunch`、`午餐`、金額與完整原始指令。
